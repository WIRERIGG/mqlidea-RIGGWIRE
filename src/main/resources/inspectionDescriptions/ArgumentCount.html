Reports a call to one of your functions with a number of arguments that none of its overloads takes, counting default values. MetaEditor rejects it with error 199, "wrong parameters count".

Example:

double Lot(double risk, int sl);
Lot(1.0, 20, 0); // Lot takes 2

Built-in functions, member calls (obj.Method()), macros and files whose includes can't all be read are not checked.
