Reports a broken contract between an indicator and the programs that read it, using literal values only.

In an indicator: a SetIndexBuffer index at or past indicator_buffers, plots that need more buffers than are declared, and an INDICATOR_DATA buffer past the buffers the plots use. MetaTrader doesn't bind that buffer for other programs: their CopyBuffer returns -1 (error 4806). Bind it as INDICATOR_CALCULATIONS instead.

In an EA or script: CopyBuffer(handle, index, ...) where handle is only assigned iCustom(..., "Name", ...) and Name.mq5 is in the project, with index a number or a #define of one, reading a buffer the indicator doesn't declare, never binds, or binds unreadably. Also an iCustom call passing more parameters than the indicator has inputs.

Computed indexes, dynamic draw types (PLOT_DRAW_TYPE), DRAW_BARS/DRAW_CANDLES and indicators outside the project are skipped, never guessed.

#property indicator_buffers 3
#property indicator_plots   1
#property indicator_type1   DRAW_LINE
...
SetIndexBuffer(2, atr, INDICATOR_DATA);   // unreadable from an EA: use INDICATOR_CALCULATIONS
