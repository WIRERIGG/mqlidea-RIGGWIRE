Reports a statement whose ; is missing. MetaEditor rejects it with error 154, "semicolon expected" (or "unexpected token" on the next line).

Example:

void OnTick()
{
   double lot = 0.1        // ';' expected
   Print(lot);
}

A statement that uses a #define macro is not reported, since the macro's body may end in ;. Nor is anything in a file whose #include files the plugin can't all read.
