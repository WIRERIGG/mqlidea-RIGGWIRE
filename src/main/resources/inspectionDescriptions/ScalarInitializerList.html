Reports a single number, string or other scalar declared with a {...} list of several values. MetaEditor rejects it with error 186, "too many initializers" (187, "'{' - constant expected", at global scope).

Example:

double lot = {0.1, 0.2};   // a double holds one value
double lots[] = {0.1, 0.2}; // an array holds several

Arrays, structures, vector, matrix and complex take value lists and are not reported.
