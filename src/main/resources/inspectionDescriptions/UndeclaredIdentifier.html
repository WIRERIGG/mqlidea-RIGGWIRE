Reports a name that nothing declares: a variable, constant or type that is not an MQL built-in and is not declared in the file, its #include files, the file that includes this header, or anywhere else in the project, and a member a class doesn't have. MetaEditor rejects both with error 256, "undeclared identifier". Calls to undefined global functions are reported by "Call to an undefined function".

Example:

class CRisk { public: double Lots(); };
CRisk risk;
void OnTick()
{
   double lots = risk.Lot();          // the method is Lots
   if(lots > MaxLots) Print(lots);    // MaxLots is declared nowhere
}

A member is checked only when the receiver's class and all its base classes are declared in the project or its headers. A file with an #include that can't be found is not checked, nor are #define, #import and #property lines.
