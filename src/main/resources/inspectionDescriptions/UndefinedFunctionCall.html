Reports a call to a function that is not an MQL built-in and is not declared in the file, its #include files or anywhere else in the project. MetaEditor rejects it with error 256, "undeclared identifier". In an MQL5 file a call to an MQL4-only function (OrderLots(), TimeHour()) is reported too, since MQL5 doesn't have it.

Example:

void OnTick()
{
   double lot = CalcLotSise(0.01);   // typo: the function is CalcLotSize
}

A file with an #include that can't be found is not checked, since the missing header could declare the name. Member and scoped calls (obj.Foo(), CFoo::Bar()) and #define / #import bodies are not checked.
